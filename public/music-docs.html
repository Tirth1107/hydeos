Help

Questions & fixes

"App not installed" error ⌄

Usually the arm64 APK on a 32-bit device. Try the universal APK. If you have a build from somewhere else installed, uninstall it first. Apps signed with different keys can't update each other.

Play Protect warns me ⌄

Play Protect flags apps that aren't from the Play Store. Hyde Music is open source and signed with the Hyde key. Tap More details › Install anyway.

Music stops when the screen is off ⌄

Some phones (Samsung, Xiaomi, OnePlus) close background apps aggressively. Set Hyde Music's battery usage to Unrestricted in Android Settings › Apps › Hyde Music › Battery.

The phone feels warm ⌄

Update to 6.3.0, which is built to run cool. For the lightest setup, set Settings › Appearance › Glass to Performance, keep High refresh rate off, and choose the Gradient player background.

A song won't play ⌄

Some tracks are blocked in certain regions. Skip to the next song, or search for another version. If it keeps happening, report it below with the song name.

How is AI Shuffle different from Shuffle? ⌄

Shuffle is a random order. AI Shuffle picks each next song to fit the one before (artist, album, length) but limits runs to two songs per artist, so a playlist flows without one artist taking over.
