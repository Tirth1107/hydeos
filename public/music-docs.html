Core Features

Audio Normalization

Uses the Web Audio API to analyze decibel levels in real-time, automatically adjusting volume for a consistent experience.

Smart Caching

Saves songs to IndexedDB. If you play that song again, it loads instantly from your disk instead of using bandwidth.

Privacy First

No account required. Playlists are stored locally, and search queries are routed through an anonymous proxy.

Installation Guide

Windows Installation

  1. Download HydeMusic-Setup.exe
  2. Run the installer
  3. If SmartScreen appears, click More Info → Run Anyway
  4. The app will install and launch instantly

Web Player (PWA)

Install as an app on Chrome/Edge:

  1. Visit the Hyde Music web app
  2. Click the install icon in the address bar
  3. Click "Install" - it will appear in your Start Menu

Troubleshooting

Music stops in background

Browser battery optimization often kills background tabs on mobile. Use the "Install App" (PWA) feature.

Song fails to load

Usually due to geo-blocking. Try skipping to the next song or searching for a generic version.

Windows App: "Unsafe File" Warning

This is expected for indie software. We don't buy corporate signing certificates from Microsoft. The app is virus-free and stable - simply click "Run Anyway".
